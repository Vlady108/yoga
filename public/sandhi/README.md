# Лендинг курса «Сандхи-Хилинг»

Статическая страница. Живёт внутри существующего Next.js-проекта, в папке `public/sandhi/`, и **никак не пересекается с основным сайтом** — Next.js отдаёт содержимое `public/` как есть, не трогая роутинг приложения.

Адрес после деплоя:

- украинская версия — `https://yoga-rosy-iota.vercel.app/sandhi/index.html`
- русская версия — `https://yoga-rosy-iota.vercel.app/sandhi/ru.html`

## Структура

```
public/sandhi/
  index.html          украинская версия
  ru.html             русская версия
  README.md           этот файл
  assets/
    hero.mp4          полное видео со звуком, 54 сек, 18 МБ
    hero-loop.mp4     беззвучная петля 12 сек для первого экрана, 0,9 МБ
    hero-poster.jpg   кадр-заглушка, пока грузится видео
    chat.js           чат-бот: вопросы и ответы на двух языках
    chat.css          оформление чата
```

Все ссылки внутри страниц относительные, поэтому папку можно перенести куда угодно — например в `public/lp/` — и ничего не сломается.

## Заявки

Сейчас заявка сохраняется в браузере посетителя и сразу открывает Telegram-бот. Чтобы заявки приходили вам, найдите в `index.html` и `ru.html` комментарий:

```
=== ТУТ ПІДКЛЮЧАЄТЬСЯ ЗБІР ЛІДІВ ===
```

и раскомментируйте `fetch(...)`, подставив адрес приёмника. В заявке уже передаётся выбранная услуга: `course`, `individual` или `consult`.

**Токен Telegram-бота в этот файл вставлять нельзя** — код страницы виден любому посетителю, и бота сможет угнать кто угодно. Токен должен лежать на стороне сервера: в Cloudflare Worker, в Google Apps Script или в API-роуте самого Next.js-проекта (`app/api/...`) — последнее удобнее всего, раз проект уже есть.

## Чат-бот

Всё в `assets/chat.js`, работает целиком в браузере. Язык берётся из `<html lang>`, но вопросы понимает и на русском, и на украинском: перед сравнением текст приводится к общей форме (і→и, ї→и, є→е, ґ→г, ё→е), поэтому «ціна» и «цена» ловятся одним ключом.

Чтобы добавить вопрос, допишите объект в массив `FAQ`:

```js
{
  k: ['ключевое', 'слово', 'ключове'],   // по каким словам срабатывает
  ru: 'Ответ по-русски',
  uk: 'Відповідь українською'
}
```

Если бот не понял вопрос — предлагает темы и даёт ссылку на живого человека, `@dawa_wonder`.

## Видео

Исходник был 4K HEVC на 190 МБ — такое не играет в браузерах и не влезает в GitHub. Пересобрано в H.264 Constrained Baseline, `yuv420p`, faststart: играет везде, включая старые Android и iOS Safari.

Автоплей в первом экране только беззвучный — это правило браузеров, обойти нельзя. Звук включается по кнопке.

При замене ролика держите формат вертикальным (9:16) и вес `hero.mp4` в пределах 50 МБ, иначе страница будет долго открываться с телефона.
